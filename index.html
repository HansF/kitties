Kitties Data API

Hourly snapshot of every animal up for adoption on adopteereendier.be, plus all shelters, as static JSON and CSV.

Open the map → every animal on one map, clustered by shelter, with photos and filters.

Start here

https://hansf.github.io/kitties/data/meta.json

meta.json is tiny and holds updated_at (last time the listings actually changed — not the last scrape), counts per category and the URL of every file. Poll it (hourly is plenty) and only re-download the data when updated_at changes.

Example

const BASE = "https://hansf.github.io/kitties/data";
const meta = await fetch(`${BASE}/meta.json`).then(r => r.json());
if (meta.updated_at !== localStorage.lastUpdate) {
  const cats = await fetch(meta.files.katten).then(r => r.json());
  const shelters = await fetch(meta.files.shelters).then(r => r.json());
  const byName = Object.fromEntries(shelters.map(s => [s.name, s]));
  cats.forEach(c => c.shelterInfo = byName[c.shelter]);
  localStorage.lastUpdate = meta.updated_at;
}

Freshness

A GitHub Action scrapes the site every hour (at :17) and commits only when something changed. Pages republishes about a minute later and responses may be cached up to 10 minutes, so new listings show up within roughly an hour. The git history of the repo is a full history of the listings.
